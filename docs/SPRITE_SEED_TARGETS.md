# Sprite seed targets

For each creature form, transparent seed approval uses a 128×128 bottom-center anchored frame. Production strips are generated from one approved seed per form, never independently frame-by-frame.

Required strips per shippable form: idle 4, attack 6, hurt 3, faint 5, resonance/special 6. The portrait atlas built from source cards is reference/UI material only and must not be used as a substitute for transparent battle animation.
